# 无限模式

完成最后一份主线订单后，游戏会在处理完该订单的正常奖励后提供三个选择：

- `结束本局`：状态变为 `won`，按正常通关结算。
- `进入无限模式`：保留当前金币、成分、物品、精粹和 Token，进入无限订单 1。
- `进入和平模式`：保留当前状态，进入和平订单 1。

无限订单固定为 10 回合。无限订单 1 需要 1000g，之后每次使用整数向上取整计算：

`下一目标 = ceil(上一目标 × 1.5)`

因此目标序列开头为 `1000, 1500, 2250, 3375, 5063, 7595`。无限模式没有胜利终点；支付失败时状态变为 `lost`。

存档状态新增：

- `endless_mode`
- `endless_order`
- `endless_target`

统计字段保存在 `stats` 中，包括已完成无限订单数、到达的最高无限订单、无限模式最高单回合金币和全局最高单回合金币。旧存档缺少无限/和平模式字段或统计字段时，自动使用 `False / 0` 安全默认值，不影响原有主线进度。

Agent 状态会额外展示 `endless_mode`、`endless_order`、`endless_target`、剩余回合，以及主线完成后的 `run_end` 选择。Agent 可执行 `choose 1` 结束本局，或 `choose 2` 进入无限模式。

和平模式使用 `peace_mode` 和 `peace_order` 状态字段。每份订单固定为7回合、0g，完成后继续下一份；金币达到1000000g时自动判定 `won`。Agent 在结算选择中使用 `choose 3` 进入和平模式。
