## 复现实验

在项目根目录运行（也可替换为项目可用 Python 路径）：

```powershell
$env:PYTHONPATH = "src"
python -m crucible_echoes.balance_experiment --patch reports/optimization_20260920/growth_trial.json --games 100 --difficulties 7 10 15 --seed 20260920 --output reports/optimization_20260920/growth_trial_result.json
```

补丁格式为JSON数组，每项包含collection、id、path、value。示例：

```json
[{"collection":"ingredients","id":"timber","path":["growth_after"],"value":6}]
```

同seed并不保证修改概率后随机路径不分歧。低于25对胜负改变时不输出会产生虚假精度的正态近似区间；任何中止局都应先排错，不能当成失败加入结论。试验仅用于数值验证，不会替候选版本修改描述、正式数据或存档。
